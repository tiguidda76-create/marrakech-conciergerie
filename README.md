# Marrakech Conciergerie Privée

Solution SaaS et plateforme de gestion hôtelière haut de gamme pour Riads & Villas à Marrakech.

## Tech Stack
- **Frontend** : Next.js 15 (App Router), TypeScript, Tailwind CSS v4, Lucide React, Recharts
- **Backend & BDD** : Supabase (PostgreSQL, Row Level Security, Auth)
- **Devise** : MAD (Dirham Marocain) & conversions EUR
- **Fuseau horaire** : Africa/Casablanca (GMT+1)
- **Commission Standard** : 25%
- **Taxe de séjour** : 11 MAD / personne / nuit (Délégation Régionale du Tourisme)
